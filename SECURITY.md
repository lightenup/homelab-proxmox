# Security policy

This repository is the infrastructure-as-code for a personal homelab. It is published for
reference; it is not a supported product.

## Reporting a vulnerability

Please **do not open a public issue or pull request** for a security problem. Report it
privately through GitHub's [private vulnerability reporting](../../security/advisories/new)
on this repository.

Particularly welcome: anything that would let a pull request, fork or workflow run reach the
self-hosted runner or the hosts it deploys to, and any credential found in the tree or history.
